# 汉化 fork 的默认语言定为简体中文

这个 fork（`r2modmanPlusChs`）把**全新安装**的界面语言定为简体中文（`DEFAULT_LOCALE = 'zh-cn'`，
并同步改了设置库的种子值），而不是沿用上游的 `en`：已经存过语言的用户不会被改写，库里存了
本版本不支持的值时仍然回退到 `en`。理由是 fork 的定位就是给中文用户用的汉化版，首次启动看到
母语比看到英文更符合预期。

## Considered Options

- **跟随系统语言**（系统语言命中 `zh*` 才用中文）：多一层隐式分支，收益只体现在首次启动；
  而且会让「装的是汉化版、看到的却是英文」这种反直觉情况出现在系统语言为英文的机器上。
- **默认 `en`，只把中文作为可选语言**：与上游完全一致、合并冲突最小，但对汉化版用户是倒退。
- **默认 `zh-cn`（选中）**：最符合 fork 的定位。代价是与上游在首次启动体验上分叉。

## Consequences

- 上游的 `MessageFormat` 里仍挂着一句 *Use for language selection screens* 的 TODO。等活动栏
  地球图标之外的语言入口被上游正式收编（或语言选择界面被重做），这个默认值需要重新协商。
- 版本号**保持与上游相同的 `3.2.20`**：应用内的「有新版本」横幅只比对上游
  `ebkr/r2modmanPlus` 的 release 列表，版本号相等即静默——不会因为做了汉化就让用户收到
  指向上游英文版的更新提示。汉化版自身用 tag `v3.2.20-chs.1` 与上游 release 区分，
  而 `3.2.20-chs.1` 这类预发布号不会被 electron-updater 当作更新推送。
